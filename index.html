📋 Checklist Verifiche Rapide (ogni riavvio / emergenza)

  • ☐ addr1050 = 1 (System Run)
  • ☐ addr1053 = 3 (OTC = Fix)
  • ☐ addr1055 = addr1005 (Setpoint ricevuto)
  • ☐ addr1088 = 2 (CentralMode = Water)
  • ☐ addr1094 = 0 (H-LINK OK)
  • ☐ LED R6 spento in QE2 (se rosso → levetta OFF in QE1)
  • ☐ LED R2 rosso quando PDC accesa (se spento → reset P1)
  • ☐ Pressione circuito 1,0÷1,5 bar
  • ☐ Display PC-ARFH1E acceso con dati C1 e ACS
